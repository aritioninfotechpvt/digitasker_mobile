# InsightLoop V5 — Feature Freeze Matrix

- Campaign → Task → Assignment → Submission → Verification → Reward/Settlement → Reporting
- Direct User, Vendor Managed and Vendor Bid sourcing modes
- Dynamic workflows and advanced survey/evidence requirements
- Fraud/trust, maker-checker QC, disputes and full audit logging
- Automation, notifications, API/webhooks, system operations
- Consent, data-retention and configurable approval chains
- White-label portal controls

- Vendor RFQ / bidding / partial awards

- Campaign budget waterfall and overspend protection

- Analytics, reports, scheduled reporting

- Communication/broadcasts and notification templates
- Roles/permissions, audit logs, governance
- API keys/webhooks, system health
- White-label tenant management
